Web interface (Web UI)

The Egnyte web interface has three main areas: the main menu on the left, the folder tree beside it, and the file/folder list in the middle — similar to Windows Explorer. Panels can be collapsed and expanded.

Home dashboard

On login you land on a dashboard with four widgets: Bookmarks, Recent Files, Links and Project Folders.

Navigation

Select Files from the main menu and click through the folder tree. Navigate back via the folder path, or make a frequently used folder your home screen (More → Set as default view).

File actions

Select an item and right-click, or use the toolbar: Create, Upload, Share, Download and More (Preview, Versions, Details, Lock, Rename, Move, Delete…).

Search

Use the search box top-right with filters such as folder scope, word matching, item type and time frame.

Preview

Click a file name to preview it in the browser; use the arrows to move between files in the same folder.

Upload and download

  • Upload: via "Upload" or drag and drop.
  • Download: select an item and choose "Download" (multiple items arrive as a zip).
  • Share: use "Share" to create links for people outside the company.

Egnyte Desktop App (Windows)

The desktop app lets you access all cloud files like a network drive on your computer, without using local space. You can also sync selected folders for offline access.

Open Egnyte to download ↗

How to download

  1. In the Egnyte web interface go to Apps & Integrations → Egnyte Apps.
  2. Click Download for Egnyte Desktop App for Windows.
  3. Run the installer and follow the steps.
  4. Sign in with your Egnyte credentials; the app appears as a network drive.
